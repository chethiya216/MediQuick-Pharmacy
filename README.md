# 💊 Pharmacy Management System

A web-based Pharmacy & Inventory Management System built with **PHP**, **MySQL**, and the **Sneat Bootstrap 5 Admin Template**. Designed specifically for retail pharmacies and medical dispensaries to manage products, dynamic batch stock, suppliers, and customer profiles.

---

## ✨ Key Features

### 📦 Product & Inventory Management
- **Detailed Product Records:** Store medical info including dosage forms (tablets, syrups, injections), strength, unit price, discounts, and prescription requirements (`Rx`).
- **Multi-Batch Tracking:** Track batch numbers, stock quantities, and expiry dates to handle perishable medical supplies efficiently.
- **Stock Control Alerts:** Monitor reorder levels to prevent stockouts of vital medicines.
- **Categorization & Suppliers:** Classify items by category (e.g., Pain Relief, Antibiotics, Skincare) and assign specific suppliers.

### 👥 Customer Management
- **Customer Directory:** Filterable list with instant search by name, email, or phone number.
- **Status Control:** Track active, inactive, or banned customer profiles.
- **Order History Integration:** Quick links to view individual customer purchase histories.

### 🎨 User Interface & Experience
- **Responsive Dashboard:** Built on Sneat Bootstrap 5 HTML Admin Template for mobile, tablet, and desktop viewports.
- **Structured Workflows:** Split-column forms, drag-and-drop image upload regions, and contextual action bars for smooth navigation.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5, Sneat Admin Template (Boxicons)
- **Backend:** PHP 8.x
- **Database:** MySQL / MariaDB
- **Server:** Apache / Nginx (XAMPP / WAMP / LocalWP supported)
